Game mode

Solo: mouse, number keys, or pad 0. Lock area and perimeter before the clock hits zero.

8BitDo / gamepad slots

P1 PAD: WAITING
P2 PAD: WAITING
P3 PAD: WAITING

Press any button on each controller so the browser can see it. P1 uses slot 0, P2 slot 1, P3 slot 2. Start on a pad begins the match.

Rounds

  1. Rounds 1–3 · Squares and rectangles, including length from area ÷ breadth.
  2. Rounds 4–5 · Corner cutouts. Remaining area subtracts. A corner bite keeps the outer perimeter.
  3. Rounds 6–7 · Paths around a field, and borders inside a sheet. Add or subtract the width twice.
  4. Rounds 8–9 · Folded corners, edge flaps, half-folds, and two joined squares.
  5. Round 10 onward · How many whole squares fit, and the unused area. Never divide the big area by the tile area.

Solo / co-op keys. Number row types. Backspace deletes. Enter locks. P1 moves with W A S D and presses with F or Space. P2 moves with I J K L and presses with O. P3 moves with the arrow keys and presses with Right Shift or Numpad 0.

Duel keys. Same cursors. P2’s press is Enter or O. Each lane has its own LOCK key. Gamepad A presses the lit key, B deletes, X or Y locks. Solo pad: Start or Y locks.

Co-op rule. The board shows one team score and one clock. Two-box blueprints split: P1 takes the first box, P2 the second, P3 assists the lit box. One-box blueprints rotate the active architect. The mouse can always help.
