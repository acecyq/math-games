Number Train Coupler

The Runaway Freight

A freight train is rolling toward the tunnel with numbers missing. Find the step, grab the crate that completes the pattern, and drop it on the flashing flatcar.

Each engineer has 3 hearts. A wrong crate stuns that crane. If an empty flatcar reaches the tunnel, the whole team loses a heart.
